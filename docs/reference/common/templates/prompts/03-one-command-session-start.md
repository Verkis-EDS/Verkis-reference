# Reusable session-start instruction

```text
Start in the active project's existing workspace. Read its thin instruction files and the
applicable canonical Common Ops rules. Inspect CWD/Git/access and relevant current evidence;
run the existing banner where available, reporting unavailable fields as unknown.
State the objective, scope, prerequisites, verification and rollback for this task.
Use the already authorized scope without repeated permission requests. Do not run legacy
check/cleanup automation as a publisher or assume template creation deploys a service.
Use existing setup/template locations; capture actual results and a concise final handoff.
```
