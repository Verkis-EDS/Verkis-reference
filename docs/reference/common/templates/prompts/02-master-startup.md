# Reusable startup brief

```text
Objective and completion condition: [fill in].
Project/workspace and use case: [fill in actual path/scope].
Authorized changes and boundaries: [fill in; existing authorization persists].
Relevant source: project README/instructions/runbook; Common Ops operating policy;
AI Practice Hub provider and skills/tools guidance; canonical manuals for lab allocation.

Inspect current state, identify unavailable checks, and propose the smallest sufficient plan.
Reuse existing templates/tools; do not install the entire catalog or create duplicate policies.
Proceed within the authorized scope once concrete prerequisites pass; clarify materially new
or unsafe actions. Record actual tests, deployment/recovery limits and rollback evidence.
Preserve objective/decisions/changed paths/checks/unresolved work in the final handoff.
```
