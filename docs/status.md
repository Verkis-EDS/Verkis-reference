# Reference maintenance status

Reviewed: 2026-10-07.

This public mirror contains reusable guidance and templates. It does not publish a lab health score or a current infrastructure inventory. Use the private manuals for operational status and the canonical access table.

The [export manifest](https://github.com/Verkis-EDS/Verkis-reference/blob/main/PUBLIC_MIRROR_MANIFEST.md) records the Common Ops source revision. Changes are generated locally from an explicit allowlist, reviewed, scanned and built before a focused Git commit. The sync command never commits or pushes.

Read the [public safety rules](standards/public-safety-rules.md) before adding material. Provider guidance and model choices require rechecking against current official documentation; examples are not live configuration.
