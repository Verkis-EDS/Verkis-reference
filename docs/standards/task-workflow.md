# Standard Task Workflow

```text
1. Ingest request
2. Clarify only if needed
3. Classify task
4. Check current status
5. Break down work
6. Define acceptance criteria
7. Identify risks
8. Plan tests
9. Execute in small steps
10. Verify each step
11. Red-team review
12. Fix or document issues
13. Update docs
14. Close out with summary and next actions
```
