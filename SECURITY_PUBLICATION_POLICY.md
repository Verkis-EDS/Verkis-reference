# Public Publication Safety Policy

This repository is public.

## Allowed

- Generic setup guides
- Templates
- Public-safe scripts
- Sanitized examples
- Workflow standards
- Agent and skill templates
- Context and memory policies
- Senior engineer personality file

## Not allowed

- Passwords
- API tokens
- SSH private keys
- WireGuard configs
- Client documents
- Vendor NDA files
- Raw internal logs
- Raw Proxmox inventory
- Raw GitLab exports
- Full private network maps

## Redaction placeholders

Use:

- `<INTERNAL_GITLAB_URL>`
- `<NAS_MOUNT_PATH>`
- `<PROXMOX_HOST>`
- `<PROJECT_NAME>`
- `<GITHUB_REPO>`
- `<TOKEN_FROM_SECRET_STORE>`
